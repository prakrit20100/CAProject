# Computer Architecture Project

CAProject.py contains all the classes needed to create a mesh and for the routing to take place.

The code reads the traffic file "traffic.txt" and coverts the given 4 values into a 2 Dimensional Array using the function read_file().

4 Objects for the router class are created to create a 2X2 mesh.

The only user input is in the choice of Routing Algorithms.

The routing for all the packets is done using the function transferPackets() the fuction can route packets using 3 algortihms:
* XY
* YX
* Utilising both XY and YX routing algorithms in case the buffer (size = 5) is full for a router

The routing done in every cycle is then logged into a text file called "log.txt".

### The code runs using the following command:
```
python3 CAProject.py
```
## Addtionally graphs can be plotted from the generated log file using the following commmands:
### Generating the bar graph for "Flits transferred over different connections"
```
python3 makebargraphpart1.py
```
### Generating the bar graph for "Latency as a function of packets sent from PE to Detination"
```
python3 makegraph.py
```
The Requirement for the project were:

1. A cycle-accurate NoC simulator which:
    * Supports XY and YX routing 
    * Supports reading the traffic information for a text file. 
    * Generates a log file which describes what is happening at each clock cycle. 
2. A program which interprets the log file generated by the simulator and plots the following graphs:
    * Number of flits transferred as a function of connections. 
    * Latency as a function of packets sent. 
3. A README file which describes:
    * The working and usage of your simulator. 
    * The usage of your graph plotter. 
    * The usage instructions. 

Out of which all have been completed.
